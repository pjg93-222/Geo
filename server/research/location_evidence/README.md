# Reviewed address evidence

These small public JSON assets support imported-list map repairs without editing voter or source geometry databases. They contain no voter identifiers, names, contacts, or private source rows. Network requests are never made while building an import.

Schema 1 has a district identifier, `entries` for confirmed parcel-address identities, and `unconfirmed` for documented searches that did not confirm an exact address. Each entry retains its source URL, retrieval date, response SHA-256, and public parcel identifier. Parcel representative points are inside the supplied polygon and are **not verified building entrances**. A municipal cadastral unit is recorded as `source.parcel_unit`; it must not be treated as a postal apartment number.

Repair requires exact house, reviewed street spelling/explicit alias, postal unit, city and state; an included reliable geocode on a reviewed neighboring street within 1.5 km; and a real same-named road within 100 m. Missing numbers, unmatched apartments, ambiguous evidence, absent neighborhood anchors, and invalid/oversized bundles remain unlocated. Parcel repairs never become evidence for another repair, and usable source geocodes remain unchanged. A null evidence ZIP means the public source did not verify a postal code: it supplies no ZIP constraint or claim, and the original record's ZIP is preserved. An explicit evidence ZIP must match every included registration for that door.

Each repair reports the original placement, parcel representative coordinate, separate road-route projection, source evidence and bundle hash. Unconfirmed entries retain search provenance and do not establish that an address is nonexistent. New evidence must be reviewed before packaging; do not insert fuzzy house matches or guess points from road ranges.

## Private source-record number recovery

`reviewed-address-corrections.json` is an optional **private profile file**, read from `STATE_DIR` (or `DATA_DIR` when no separate state directory is configured). Never package it in source releases or portable applications: it links an opaque person identifier to original source address evidence. Back up any existing file before an atomic, reviewed replacement. It is bound to the exact district and source SHA-256 and keeps original registration, residential and mailing fields, source row, review provenance and its own hash. It cannot alter the source database.

The overlay can fill only a blank registration house number when the same verified source row's residential and mailing full addresses agree on number/street/unit/locality. Existing house numbers and unaudited household members are never changed. The recovered number is committed to an imported payload only after the public parcel, included neighborhood anchor and real-road checks succeed. Vendor alternate-address coordinates are retained as evidence and never used as the replacement map point. The returned correction and door evidence explicitly preserve the original blank registration number.

The workbook image supports the street layout but contains no house numbers. A separate private, dataset-bound audit can recover a missing registration number only when the same verified source record has concordant residential and mailing addresses and this public parcel evidence succeeds. The original registration value and conflicting vendor coordinates remain in correction provenance. This public bundle contains no private record identifiers and does not itself authorize filling blank house numbers.
